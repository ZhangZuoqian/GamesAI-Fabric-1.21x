# GamesAI-Fabric-1.21.x

GamesAI mod for Minecraft 1.21.9 - 1.21.11 (Fabric).

## Downloads

Download the jar for your Minecraft version from the [Releases page](../../releases/latest).

| Minecraft Version | Jar File                          |
|-------------------|-----------------------------------|
| 1.21.9            | `games_ai-0.2.0+1.21.9.jar`       |
| 1.21.10           | `games_ai-0.2.0+1.21.10.jar`      |
| 1.21.11           | `games_ai-0.2.0+1.21.11.jar`      |

## Installation

1. Install [Fabric Loader](https://fabricmc.net/use/) for your Minecraft version.
2. Install [Fabric API](https://modrinth.com/mod/fabric-api).
3. Drop the jar from Releases into your `mods/` folder.

## Build Configuration

The `build-configs/` directory contains the Stonecutter + Gradle configuration
used to produce multi-version jars from a single source tree.
